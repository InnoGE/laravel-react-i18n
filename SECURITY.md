# Security policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| 3.x     | Yes       |
| < 3.0   | No (upstream `laravel-react-i18n`) |

## Reporting a vulnerability

Please do not open a public issue. Report it privately through
[GitHub's vulnerability reporting](https://github.com/InnoGE/laravel-react-i18n/security/advisories/new).
We answer within a few working days and publish a fix and an advisory once it is released.
